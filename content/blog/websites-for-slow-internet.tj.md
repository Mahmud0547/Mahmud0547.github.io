Дар Душанбе, дар 4G-и хуб, ин сайт камтар аз як сония кушода мешавад. Дар деҳаи кӯҳӣ, дар 2G, ҳамин саҳифа метавонад **зиёда аз як дақиқа** бор шавад. Сайт тағйир наёфтааст. Танҳо роҳ то он тағйир ёфтааст.

Аксари сайтҳоро дар идора бо интернети тез месозанд ва месанҷанд, ва ин як дақиқаро касе пай намебарад. Ин дарс нишон медиҳад, ки он аз куҷо пайдо мешавад ва ин сайт — ҳамоне, ки шумо ҳоло мехонед — қисми зиёди онро чӣ тавр сарфа мекунад.

## Саҳифа як файл нест

Вақте шумо саҳифаро мекушоед, браузер аввал як файли хурдро зеркашӣ мекунад: **HTML**, матн ва сохтори саҳифа. Баъд HTML мегӯяд: «ба ман инҳо ҳам лозиманд» — ва браузер боқимондаро меорад:

- **CSS** — услубҳо: рангҳо, андозаҳо, ҷойгиршавӣ;
- **ҳарфҳо (шрифтҳо)** — худи ҳарфҳо, агар сайт шрифти худро дошта бошад;
- **JavaScript** — коде, ки тугмаҳо, машқҳо ва аниматсияҳоро ба кор меандозад;
- **суратҳо** ва дигар тасвирҳо.

Ин саҳифаи асосии ҳамин сайт аст, ки аз рӯи сохтаи воқеӣ чен карда шудааст:

| Қисмат | Андоза |
|---|---|
| Худи саҳифа (HTML) | 19 КБ |
| Услубҳо (CSS) | 10 КБ |
| Ҳарфҳо (шрифтҳо) | 59 КБ |
| JavaScript | 183 КБ |
| Суратҳо | 342 КБ |
| **Ҳамагӣ** | **613 КБ** |

Зиёда аз нисфи ҳама чиз — суратҳо, ва аксари онҳо дар поёни саҳифа ҷойгиранд, ки бисёр меҳмонон то он ҷо намерасанд.

> [!IDEA] Қисмати вазнинтарини саҳифа кам ҳамон қисмате мешавад, ки одамон барояш омадаанд. Аввал бифаҳмед, ки чӣ бештар вазн дорад, баъд қарор диҳед, ки чиро кам кунед.

## Интернети суст ду бор зарар мерасонад

Пайваст на як, балки ду рақам дорад:

- **Суръат** — дар як сония чанд байт гузашта метавонад. Дар 4G-и хуб тақрибан 10 мегабит дар сония; дар 2G-и заиф тақрибан 70 килобит — **140 маротиба камтар**.
- **Таъхир** — як сафари «савол — ҷавоб» чӣ қадар давом мекунад, ҳатто барои файли хеле хурд. Дар 4G тақрибан 50 миллисония; дар 2G зиёда аз як сония.

Браузер саҳифаро дар як сафар намегирад. Вай HTML-ро мепурсад, интизор мешавад, онро мехонад, баъд услубҳо, ҳарфҳо ва кодро мепурсад, боз интизор мешавад, баъд суратҳоро мепурсад. Ҳар мавҷи дархостҳо боз таъхирро пардохт мекунад. Барои ҳамин дар пайвасти суст шумо барои **ҳар байт** ва барои **ҳар интизорӣ** пардохт мекунед.

## Сайт чӣ тавр мефаҳмад, ки пайваст суст аст

Баъзе браузерҳо — Chrome, Edge, Samsung Internet ва аксари браузерҳо дар Android — ба саҳифа дар бораи пайваст хабар медиҳанд. JavaScript ду чизро хонда метавонад:

- **effectiveType** — тахмини худи браузер: «4g», «3g», «2g» ё «slow-2g»;
- **saveData** — оё шахс дар телефон ё браузер сарфаи трафикро фаъол кардааст.

Ин сайт ҳарду қиматро бо скрипти хурде месанҷад, ки **пеш аз кашидани ягон чиз** иҷро мешавад, барои ҳамин саҳифа ҳеҷ гоҳ аввал версияи вазнинро нишон намедиҳад. Ин мантиқи воқеӣ аст, каме соддашуда:

```js
var connection = navigator.connection;
var slow = connection && (connection.saveData ||
  ["slow-2g", "2g", "3g"].includes(connection.effectiveType));
var choice = localStorage.getItem("lite"); // "on", "off" ё ҳеҷ чиз

if (choice === "on" || (choice !== "off" && slow)) {
  document.documentElement.setAttribute("data-lite", "auto");
}
```

Онро мисли ҷумла хонед: *агар шахс версияи сабукро хоста бошад, ё аз он даст накашида бошад ва пайваст суст бошад — онро фаъол кун.* Интихоби худи шахс ҳамеша аз тахмин қавитар аст.

> [!WARNING] Safari ва Firefox дар бораи пайваст хабар намедиҳанд — онро пинҳон медоранд. Сайт ҳеҷ гоҳ набояд танҳо ба тахмин вобаста бошад. Барои ҳамин дар поёни ин сайт гузарондани **Версияи сабук** ҳаст — барои ҳама ва дар ҳар браузер.

## Версияи сабук чиро тағйир медиҳад

Вақте версияи сабук фаъол аст, дар боло ёддошти зард инро мегӯяд ва тугмаи **Версияи пурраро нишон диҳед**-ро пешниҳод мекунад. Баъд:

1. **Аниматсия нест.** Тасвирҳои ҳаракаткунанда дар телефонҳои арзон батарея ва қувваи протсессорро сарф мекунанд.
2. **Суратҳо интизор мешаванд.** Ба ҷои ҳар сурат тугма ҳаст: **Суратро нишон диҳед · 157 КБ**. Шумо андозаро пеш аз пардохт мебинед.
3. **Машқҳо интизор мешаванд.** Машқҳои интерактивӣ дар ин дарсҳо ҳамчун **Машқро бор кунед** намоён мешаванд ва коди худро танҳо пас аз пахш зеркашӣ мекунанд.

Чизе, ки вай тағйир **намедиҳад**, ҳамон қадар муҳим аст: тамоми матн, ҳар пайванд, шакли тамос ва ҳамаи забонҳо боқӣ мемонанд. Версияи сабук сайти камбағалтар нест. Ин ҳамон сайт аст, ки пеш аз фиристодани қисматҳои вазнин мепурсад.

> [!IDEA] Версияи сабуки хуб интизориро нест мекунад, на мундариҷаро. Агар дар версияи сабук кори муҳимеро карда натавонед, вай сабуктар нест — вай вайрон аст.

## Ҳилае, ки ҳама чиз ба он такя дорад: суратҳои пинҳон зеркашӣ намешаванд

Суратҳои поёни саҳифа ҳамчун **танбал** қайд шудаанд: браузер онҳоро танҳо вақте зеркашӣ мекунад, ки ба экран наздик мешаванд. Ва сурати танбале, ки пинҳон аст, умуман зеркашӣ намешавад. Барои ҳамин версияи сабук суратҳоро пинҳон карда, тугмаро нишон медиҳад. Вақте онро пахш мекунед, сурат пайдо мешавад — ва танҳо он вақт браузер онро меорад. Барои худи сарфа ягон коди иловагӣ лозим нест: корро браузер мекунад.

## Барои онҳое, ки сайт фармоиш медиҳанд

Агар меҳмонони шумо берун аз пойтахт зиндагӣ кунанд, аз интернети мобилӣ истифода баранд ё барои ҳар мегабайт пардохт кунанд, пеш аз қабули сайт се савол диҳед:

1. **Саҳифаи асосӣ чанд вазн дорад?** Ҷавоби хуб — рақам, масалан «613 КБ, аз онҳо 342 КБ суратҳо». «Вай тез аст» ҷавоб нест.
2. **Оё онро дар пайвасти суст санҷидаанд?** Ҷавоби хуб: ҳа, бо сусткунӣ то 3G, ва ҳама чизи муҳим кор мекунад.
3. **Дар 2G ё бо сарфаи трафики фаъол чӣ мешавад?** Ҷавоби хуб: аввал матн ва тугмаҳо меоянд; суратҳо, видео ва иловаҳои вазнин интизор мешаванд ё хурдтар меоянд.

## Луғати хурд

- **HTML** — файл бо матн ва сохтори саҳифа; браузер онро аввал зеркашӣ мекунад.
- **CSS** — услубҳо: рангҳо, андозаҳо, ҷойгиршавӣ.
- **JavaScript** — коде, ки дар браузер кор мекунад ва саҳифаро интерактивӣ месозад.
- **Килобайт (КБ)** — воҳиди андоза; 1000 КБ тақрибан як мегабайт аст.
- **Суръат (гузариш)** — пайваст дар як сония чӣ қадар додаҳо интиқол медиҳад.
- **Таъхир** — роҳи як дархост то ба он ҷо ва баргашт чӣ қадар давом мекунад, ҳар қадар хурд бошад ҳам.
- **Боркунии танбал** — зеркашии тасвир танҳо вақте ки онро ҳозир мебинанд.
- **Сарфаи трафик** — танзими телефон ё браузер, ки аз сайтҳо хоҳиш мекунад камтар фиристанд.
