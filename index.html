A bit about me

I'm a Computer Science student and frontend developer based in Dushanbe, Tajikistan. I build web interfaces and tools using HTML, CSS, JavaScript, and Supabase as a backend.

My recent project — Kamarob Nature Fund — is a multilingual conservation website (EN / RU / DE / TJ) with a live Supabase backend, dynamic slug-based routing, and a custom i18n system, deployed on GitHub Pages.

I take on freelance projects through Fiverr and Upwork while continuing to grow as a developer. I write clean, readable code that's easy for any developer to pick up and continue.
